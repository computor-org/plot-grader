# Round 2: current vision models, 2026-09-28

Same judge task as round 1 (`docs/history/2025-11-first-trials.md`), run on
four models and two interfaces. Raw rows are in `data/vlm_eval/` (gitignored),
and the endpoints are configured in `configs/vlm_endpoints.json`.

## Setup

| Name | Model | Where |
|---|---|---|
| `qwen3-vl-4b` | Qwen3-VL-4B-Instruct MLX 8-bit (the round-1 model) | Apple Silicon server, oMLX, chat only |
| `4b` | Qwen3.5-4B MLX 8-bit | Apple Silicon server, oMLX |
| `flash-next` | Qwen3.8-Flash-Next | Apple Silicon server, oMLX |
| `27b` | Qwen3.8-27B Q4_K_XL + mmproj | GPU workstation, llama.cpp, 1 slot |

- **Modes:** `chat` is the JSON verdict prompt through chat completions, at
  temperature 0.1 with reasoning off. `jev` is `/v1/systemone` with yes/no
  questions, PASS if P(overall) ≥ 0.5.
- **Views:** `student` is the round-1 prompt with only the student image.
  `pair` shows the reference, then the student plot.
- Latencies are single-stream. The Apple Silicon server was also serving other users.

## A. Round-1 rerun: 15 synthetic `plot_docstr` variants, 3 repeats

Accuracy is on the 10 labelled variants × 3 repeats. "False pass" counts
wrong plots judged PASS.

| model | mode | view | acc | false pass | p50 s |
|---|---|---|---|---|---|
| all four | chat, jev | student | 0.50 (0.43 for qwen3-vl-4b) | all or none | 1–12 |
| qwen3-vl-4b | chat | pair | **0.90** | 3 | 1.0 |
| 4b | chat / jev | pair | 0.80 | 6 | 1.6 / 2.5 |
| flash-next | chat / jev | pair | 0.80 | 6 | 6.6 / 9.3 |
| 27b | chat / jev | pair | 0.80 | 6 | 6.2 / 6.0 |

- **Without the reference the task is meaningless.** Every model answers the
  same for every student-only case: PASS for all (Flash-Next, 27B, 4B with
  JEV) or FAIL for all (4B chat, Qwen3-VL-4B). Round 1's "independent judge"
  (commit 31c09ba) was this setup.
- **With the reference,** all new models miss the same two negatives: the
  data off by 10 % (a slightly steeper red line) and the missing x-axis label
  (a single letter "x"). Qwen3-VL-4B misses only the first. Tier 1 catches
  both from the plot data.
- **Verdicts are stable:** only 5 of 210 (model, view, case) triples changed
  over the 3 repeats, 4 of them for Qwen3-VL-4B.

## B. 120 real cases from 17 exercises

`scripts/build_eval_set.py` collected solutions for every Computor exercise
with a graphics test (localTests, older assignment copies, blind LLM
solutions) plus six mutations of each reference. The official harness labels
them: PASS if all graphics tests pass. That gives 55 solutions (35 PASS,
20 FAIL) and 65 mutants (20 PASS, 45 FAIL). The pair view was used, with
1 repeat.

| model | mode | failing solutions caught | correct solutions failed | mutants flagged | unusable | p50 s |
|---|---|---|---|---|---|---|
| Tier 1 (data) | – | 20/20 | 10/35 | 62/65 | – | <0.1 |
| 27b | chat | 20/20 | 11/35 | 60/65 | 0 | 9.2* |
| 27b | jev | 20/20 | 11/35 | 62/65 | 0 | 12.4* |
| flash-next | chat | 20/20 | 11/35 | 62/65 | 0 | 3.9 |
| flash-next | jev | 17/20 | 9/35 | 60/65 | 0 | 9.4 |
| 4b | chat | 15/20 | 8/35 | 47/65 | 1 | 2.3 |
| 4b | jev | 14/20 | 8/35 | 49/65 | 0 | 2.5 |
| qwen3-vl-4b | chat | 18/20 | 11/35 | 46/65 | 6 | 2.3 |

\* This 27B run overlapped with the synthetic rerun on the same single-slot
server. The clean latencies from part A are 6.2 s for chat and 6.0 s for JEV.

- **Agreement with the official tests is only 62–73 % for every judge,
  Tier 1 included.** The disagreements are almost all FAIL verdicts on
  solutions the tests pass. They are real visual differences that the tests
  do not check: an extra legend, blue instead of red, a German title instead
  of English, solid instead of dashed. 20 of the mutants change colour, line
  style, marker, labels or data and still pass the tests.
- **Visual detection:** the 27B and Flash-Next (chat) find 92–95 % of the
  mutants and catch every failing solution. The 4B (Qwen3.5) finds 72–75 %
  and misses 5–6 failing solutions. The round-1 Qwen3-VL-4B finds 71 %, and
  6 of its 120 replies are unusable (JSON cut off at 250 tokens).
- **Chat and JEV give almost the same verdicts.** JEV adds probabilities
  (Brier 0.22–0.24 against the harness labels) but is not faster here. The
  cost is reading the two images: on the 27B, the chat reply (about 90
  tokens) takes 6.2 s, JEV with 6 questions 6.0 s, and JEV with only the
  overall question 4.9 s. JEV would gain with reasoning on, or with cached
  images, neither of which applied here.

## What changed in a year

- **The old 4B was not bad at comparing two plots.** On the 15 variants it
  was the best (0.90), but it fails on unusable output (5 % of replies) and
  on the broader set (71 % of mutants).
- **Round 1's weak impression came mostly from the setup,** not the model:
  one image, no reference, a 250-token cap.
- **The large current models (27B, Flash-Next)** reliably see the visual
  differences on the same plots that Tier 1 sees, with no unusable replies,
  in 4–6 s. They still miss small differences (a 10 % slope change, a
  one-letter label).
- **The model that decides the verdict is Tier 1 or the official tests.** A
  vision model adds explanations and handles tasks without exact data
  checks. The pass/fail policy has to decide whether colours, legends and
  titles that the tests ignore should count.
